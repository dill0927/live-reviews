# AWS アカウントと無料枠の条件の確認

Type: task
Status: resolved
Blocked by: —

## Question

使用する AWS アカウントの有無・作成時期・プラン（2025年7月以降の新しい無料プラン／クレジット制か、従来の12か月無料枠か）を確認し、Lambda・API Gateway HTTP API・S3・CloudFront が実質無料で運用できる条件を事実として記録する。HITL：アカウント情報は本人にしか確認できないため、エージェントは確認手順のチェックリストを渡す。AWS Budgets のアラート（例：$1）設定の要否もあわせて記録する。

補足（匿名投稿の不正対策の調査から）：このアカウントが CloudFront 定額制の Free プランの対象になるか（「AWS Free Tier 使用中のアカウントは対象外」という条件に当てはまるか）も確認する。

## Answer

2026-10-20 に、ルートユーザーの `aws login`（一時認証情報）と読み取り専用のコマンドで点検した。

- **アカウント**：既存のアカウントを使う。作成日は **2024-12-06**。2025-07-15 より前に作られた従来型のアカウントで、新しい Free/Paid プランの仕組みは適用されていない（`freetier get-account-plan-state` はデータなし）。
- **無料枠**：12 か月の無料枠は 2025-12 に終わっている。新規向けの $200 クレジットは、既存アカウントなので対象外（AWS 無料利用枠 FAQ による）。使えるのは Always Free 枠だけ（Lambda の月 100 万リクエスト、CloudFront の月 1TB / 1,000 万リクエストなど）。API Gateway HTTP API と S3 は最初から従量課金になる（HTTP API は 100 万リクエストあたり約 $1）。
- **課金の実績**：2024-12〜2026-09 の請求書は 1 件もない。Cost Explorer は有効化されていない。
- **セキュリティ**：ルートユーザーはパスキーの MFA を設定済みで、アクセスキーはなし。IAM ユーザーは 0 人。IAM ロールはサービスが自動で作るもの 3 つだけ（Support、Trusted Advisor、Resource Explorer）。Resource Explorer のインデックスが ap-southeast-2（シドニー）に 1 つある（2026-10-19 作成。無料）。
- **CLI**：AWS CLI v2.38.1 を `~/.local/bin` に入れた。ルートでのログインは `aws login --profile sekirepo-root`。
- **CloudFront 定額制 Free プランの加入条件**：まだ未確認。12 か月の無料枠は終わっているので「無料枠を使用中」には当たらない可能性が高いが、実際の画面で確かめるのは「画像パイプラインの決定」「匿名投稿の不正対策の決定」で行う。
- **予算アラート**：必要。最初に AWS リソースを作る前に設定する（月 $1 の予算アラートなど）。
